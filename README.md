# 🛒 E-Commerce Maven Project

## 📖 Overview

A simple E-Commerce web application built using **Java, Spring Boot, Maven, and MySQL**. Users can register, log in, browse products, add items to their cart, and place orders seamlessly.

---

## ✨ Features

✅ User Registration & Login
✅ Product Browsing
✅ Shopping Cart Management
✅ Order Placement
✅ Product Management (CRUD)
✅ MySQL Database Integration
✅ REST API Support
✅ Maven Dependency Management

---

## 🛠️ Technologies Used

* ☕ Java
* 🍃 Spring Boot
* 📦 Maven
* 🗄️ MySQL
* 🔗 Spring Data JPA
* 🎨 HTML, CSS, JavaScript
* 🅱️ Bootstrap

## 📋 Prerequisites

* JDK 17+
* Maven

## 🚀 Getting Started

### 1️⃣ Clone the Repository

```bash
git clone <repository-url>
```

### 2️⃣ Navigate to Project Directory

```bash
cd e-commerce-maven
```

### 3️⃣ Configure Database

Update your MySQL credentials in:

```properties
application.properties
```

### 4️⃣ Build the Project

```bash
mvn clean install
```

### 5️⃣ Run the Application

```bash
mvn spring-boot:run
```

### 6️⃣ Access the Application

🌐 Open:

```text
http://localhost:8080
```
